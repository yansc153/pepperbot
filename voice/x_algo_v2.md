## 一、必须刻进每条推文的 5 条硬规则

### 规则 1：质量分 ≥ 0.4 才算"初筛通过"

Grox 对每条新帖打 `quality_score`，门槛 0.4。低于这条线 → 后续所有召回赛道压制。

**怎么过线**：
- 内容有清晰论点（不是流水账）
- 至少有一条具体数据 / 时间 / 来源
- 配图有信息量（图表/对比/示意图 > 装饰图/纯文字海报）
- 视频有结构（不是一镜到底无剪辑）

**怎么会挂**：
- 单帖 < 50 字 + 一张图（"凑数贴"）
- AI 模板化句式（统一开头、固定结构）
- 一稿多发（哪怕换词）

---

### 规则 2：slop_score 是 AI 账号的命门

灌水分 1-3 档，越高越被判"AI 水帖"。pepperbot 本质就是 AI 生成账号，**默认就在高风险靶上**。

**触发高 slop 的行为**：
- 一稿多发（同一话题换说法重发）
- 模板化开头（"今天聊聊…" "最近发现…" "不得不说…"）
- 单帖只有几个字 + 一张图
- 配音乐 + 一段废话的视频
- 通用句式连用（"其实呢" "说白了" "归根结底"）

**规避**：
- 每条用不同的开场（hooks_ai.md 的 7 个公式轮换）
- 数据/时间/具体场景必须有一个
- 同一选题 48 小时内禁止重发

---

### 规则 3：首句钩子决定 not_dwelled 信号

X 算法把"用户快速划走"标记为**主动负向信号**。第一行抓不住 = 算法减分。

**首句必须满足三选一**：
- (a) 具体观察：「X 公司今天悄悄改了 API 定价」
- (b) 反共识：「我不认为 Sora 2 是视频模型」
- (c) 数据/事实：「Anthropic 估值 9000 亿，3 个月翻 2.4 倍」

**禁止的首句**：
- 「最近…」「今天…」「关于 X，我想说…」
- 「不知道大家有没有…」
- 「让我们聊聊…」「分享一下…」
- 任何"自我介绍"型开场

---

### 规则 4：每条必须配图，无图不发（隐性降权防御）

X 算法默认把"标签缺失"的帖子打成 **MediumRisk**——避免插在广告旁边、隐性降权。

**配图选择优先级**：
1. 原推文截图（screenshot_tweet 抓的 article 截图）— 最直接
2. 原文章 og:image — 大多新闻站有
3. 数据图 / 对比图 / 示意图
4. 最后才考虑：无图 → **skip 整条 item**，绝不发纯文字

**配图禁忌**：
- 装饰性图片（无信息量的"配氛围"图）
- 🔥🚀📈 表情符号图（算法识别为低质装饰）
- 边缘/敏感配图（健身 / 艺术 / 新闻配图都要谨慎，PTOS deluxe 复核会翻案）

---

### 规则 5：圈层比泛粉丝重要（mutual_follow_jaccard）

X 用 MinHash + Jaccard 算"你和目标读者的共同关注圈相似度"。圈层不对 = 被算法判"圈外人" = 推不动。

**pepperbot 的圈层定位**：AI / 创业 / OPC（One Person Company）

**圈层动作（写手要记住）**：
- 用 AI 圈黑话（agentic、推理时计算、wrapper、moat、token-bound、context engineering、computer use）
- 引用 AI 圈具体事件（不是"AI 行业"，是"Cursor 4.0"、"Anthropic Skills"）
- 提具体 KOL 名字（不是"业内人士"，是 @sama / @karpathy / @op7418）
- 在 KOL 帖子下高质量评论（borrowed reach）

## 二、评论生成的硬规则（KOL 互动）

X 算法对每条评论独立打分 0-3，**0 分会触发 spam 标签，影响账号信用**。

**禁止的评论（= 0 分 = spam）**：
- 「+1 学到了」「沙发」「占楼」
- 「太对了」「真的」「赞」
- 「求互关」「关注我」（任何形式）
- 单纯表情符号

**合格评论必须满足三选一**：
- (a) 实测数据：「我自己测了一下 X，发现 chunk 256 以下才稳」
- (b) 行业内幕 / 一手观察：「上周跟 Y 公司聊了，他们已经在做 Z」
- (c) 反共识 / 补充视角：「但 RAG 在 1M context 之后其实有反效果」

## 三、8 类"误杀风险"自查表

| 风险 | 触发场景 | pepperbot 规避动作 |
|---|---|---|
| 话题标签漂移 | 内容混跨 AI/币圈/娱乐 | 严守 AI/创业话题，禁止跨话题 |
| 视频过滤一刀切 | 用户开"少看视频" | pepperbot 暂不发视频 |
| VF 连带责任 | 引用被处罚的账号 | KOL 列表定期清洗，避开高风险账号 |
| 静音词 token 误匹配 | 含通用短词 | 内容多发几次（不同表述）降低误伤 |
| 品牌安全 MediumRisk | 标签缺失 / 边缘配图 | 配图必有，且明确话题 |
| 私密账号被静默排除 | is_protected = true | 保持公开账号 |
| 拉黑关系传染 | 与"对家"互动 | 不和明显对家论战 |
| 缓存命中跳过实时算法 | 重度用户 | 关键内容靠 in-network 互动触达 |

## 四、发推前最后一道关（写手自查清单）

每条推文发布前依次过：

1. **首句**：满足规则 3 三选一？
2. **slop**：avoid_slop.md A 类全过？
3. **质量分自评**：有论点 + 有数据 + 有具体场景？
4. **配图**：有图且非装饰？
5. **话题**：明确 AI/创业，无跨话题？
6. **黑话**：用了至少 1 个 AI 圈具体词/事件/人？
7. **去重**：48 小时内是否发过相似论点？

任何一项不过 → 重写或 skip。
