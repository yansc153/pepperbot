# 反 AI 腔检查表 / Avoid-Slop（@pepperfr1ends 版）

> 内容生成后、发布前必须过这个检查表。
> 命中任何一条 → 改写或 kill。
>
> 分三个等级：🚫 立刻 kill / ⚠️ 必改 / 💡 慎用

---

## A 类：立刻 kill 🚫（出现一次就删稿重写）

### A1. AI 腔通用词
- 「赋能」「打造」「构建」「构筑」「布局」「业态」
- 「让我们深入探讨」「让我们一起来看看」「不难发现」
- 「值得我们深思」「引发广泛关注」「具有重要意义」
- 「综上所述」「总而言之」「概括来说」
- 「在当今 [X] 时代」「随着 [X] 的快速发展」
- 「站在风口」「迎来机遇」「迈向新高度」
- 「数字化转型」「赋能千行百业」「践行使命」

### A2. 自杀词
- 「必涨」「稳赚」「无风险套利」
- 「建议买入 / 卖出」「强烈推荐」
- 「内幕消息」「庄家」（非历史回顾语境）
- 「跟我喊单」

### A3. 万能模糊词
- 「专家表示」「业内人士透露」「权威人士指出」（= 没有来源）
- 「数据显示」（不带具体数据）
- 「研究表明」（不带研究名）
- 「相关人士」「有关方面」

### A4. 排版症
- 破折号 `——`（出现一次就 kill）
- 三个并列短句无句号：「不焦虑。不慌张。不冲动。」
- 全段感叹号轰炸（连续 ≥ 2 个 `！`）
- 行尾句号（推文中任何一行以「。」结尾 → kill）
- 结构标签（「对的部分：」「错的部分：」「问题在于：」「值得关注：」→ kill）
- 两行文字之间没有空行（紧贴排版 → kill）

### A5. v2 增量
- 「市场已经证明」— 把价格波动包装成结论

### A6. v3 增量（从真实改稿中提取）
- 元评论句式：「这条消息的重点不是 X 而是 Y」「关键不在 A 而在 B」— 直接说 Y/B
- 强行 OPC 关联：每条都往「一人公司」「OPC 创业者」上拉 — 话题自己够硬就直接说
- 分析框架式写作：把推文写成分析报告（分点 + 标签 + 总结）— 像说话不像写报告

## B 类：必改 ⚠️（命中要重写表达）

### B1. 模糊量化
- 「大幅增长」→ 改成「增长了 X%」
- 「显著下滑」→ 「跌了 N 个点」
- 「不少人」→ 「我朋友圈里 N 个做 AI 的」
- 「市场普遍认为」→ 「我看到的 N 个分析师里 M 个这么说」

### B2. 价值评判空话
- 「具有重大意义」→ 删掉或改成「对 [谁] 来说意味着 [什么具体后果]」
- 「值得关注」→ 「我盯了三周」或「我会盯 X，因为 Y」
- 「不容忽视」→ 删
- 「至关重要」→ 删，让事实自己说话

### B3. 万能动词
- 「驱动」「带动」「引领」→ 用更具体的动词
- 「优化」→ 「降本」「提速」「砍了 3 个步骤」
- 「赋能」→ 「让 X 能够 Y」

### B4. 平庸主语
- 「投资者应当…」→ 「我自己 / 我朋友」
- 「我们要…」→ 「我打算」
- 「市场告诉我们…」→ 「这周的数据是 X」

### B5. v2 增量
- 「本质上」→ 删除，直接写具体机制
- 「长期来看」→ 「到 YYYY-MM 前，我先看 X 能不能兑现」
- 「效率提升」→ 「原来 N 步，现在 M 步」

---

## C 类：慎用 💡（看场景，默认避免）

### C1. 万能开头
- 「最近…」→ 给具体时间「上周三」
- 「关于 X，我想说…」→ 直接说
- 「不知道大家有没有…」→ 直接陈述

### C2. 互联网套话
- 「家人们」「集美们」「友友们」（创业账号别用）
- 「真的栓 Q」「绝绝子」（对目标受众违和）
- 「绝了」「神了」「炸裂」（除非真的）

### C3. 自我贬低式开场
- 「我个人比较菜…」→ 谦虚不是开场
- 「以下纯属个人观点…」→ 全部内容都是个人观点
- 「轻喷…」→ 喷就喷，不用预防针

### C4. emoji 滥用
- 表情符号每条 ≤ 2 个
- 🔥🚀📈📉 — 别用，每个账号都用烂了

## 校验流程

写完一条草稿，依次过：

1. A 类扫描 → 命中任意一条 → 删稿重写
2. B 类扫描 → 命中 → 单条改写
3. C 类扫描 → 命中 ≤ 2 条 → 通过；> 2 条 → 重写
4. 正向检查：是否符合 voice_profile.md 的 5 do / 5 don't
5. 打分：用 config/filter_rules.md 评分
