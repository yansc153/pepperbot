# AI 内容模板 — @pepperfr1ends

字数：≤ 280
目标：展示 AI 实操能力 + 建立创业者人设
每条必须配图。

---

## 结构骨架

```
[钩子 — 实测结论 / 项目挖掘 / 快评]

[2-3 个具体细节 — 不是营销话术]

[给谁用 / 不给谁用]

[作者立场：我会怎么用 / 我不会怎么用]
```

---

## 4 种推荐结构

### 结构 1：实测评价

```
用了 [产品] [N 天]，给个真实评价：

值的地方：[具体场景]
不值的地方：[缺陷]

适合：[谁]
不适合：[谁]
```

### 结构 2：创业者 × AI 应用（差异化最强）

```
我用 [AI 工具] 做 [创业任务] 的工作流：

1. [步骤]
2. [步骤]
3. [步骤]

[结果 / 省了多少时间]
[1 个坑要避]
```

### 结构 3：GitHub 项目挖掘

```
GitHub 挖到一个宝藏：

[项目名]
[Star 数] ⭐
[一句话功能]

适合：[场景]
不适合：[场景]
```

### 结构 4：产品发布快评

```
[产品 X] 刚发了。

[1 句话：对谁意味着什么变化]

我个人会 [换/不换/观望]，因为…
```

---

## 必须做 vs 必须不做

✅ 必须做：
- 带个人立场（"我会 / 我不会"）
- 给具体场景/用法/时间投入
- 说出至少 1 个缺点（建立可信度）
- ≤ 280 字

🚫 必须不做：
- 复读 release notes / 官方文案
- 列纯 benchmark 数字不说意义
- 「这是改变行业的产品」这种空话
- 全是英文术语堆砌
- 超过 280 字
