## 钩子公式 1：实测结论先行

```
用了 [产品/工具] [N 天]，给个真实评价：
[结论：值不值 + 给谁]。
```

例句：
- 「用了 Claude Code 整整 30 天，每天 8 小时。给个真实评价：值，但前提是你已经会写代码」
- 「Cursor Background Agent 用了一周。结论：简单 CRUD 直接搞定，复杂逻辑还会翻车」

---

## 钩子公式 2：我用 AI 做 X 的 workflow

```
我用 [AI 工具] 做 [具体任务] 的流程。
省了 [N 小时 / N 倍效率]。
```

例句：
- 「我用 Claude Code 搭了一套自动化内容工厂。每天自动生成 10 条推文草稿，省了我 3 小时」
- 「我让 Claude 帮我读竞品文档的 prompt（贴出来）。原来 4 小时的工作 30 分钟搞定」

为什么最爆：**创业者人设 × AI 应用 = 别人没法抄**

## 钩子公式 3：GitHub/产品挖掘

```
GitHub 挖到一个宝藏项目：
[项目名] — [Star 数] ⭐
[一句话功能]
适合：[谁]
不适合：[谁]
```

例句：
- 「GitHub 挖到一个宝藏：browser-use ⭐ 15k。用 AI 控制浏览器做自动化。适合：想自动化重复操作的人。不适合：完全不会 Python 的人」

---

## 钩子公式 4：产品发布快评

```
[产品 X] 刚发布。
[1 句话 it changes for whom]。
我个人会 [换/不换/观望]，因为…
```

例句：
- 「Claude 4.7 刚发了。对做 OPC 的人最大变化是：一次能处理整个项目了。我立刻全切，因为我天天让它写代码」

不要做：复读 release notes、列 benchmark 数字。
要做：给立场 + 给具体场景。

## 钩子公式 6：踩坑预警

```
关于 [AI 产品/玩法]，我踩过 [N] 个坑：
1. [坑 1] — [损失/后果]
2. [坑 2] — [损失/后果]
你要是刚开始用，别走我老路。
```

## 钩子公式 7：对比型

```
[工具 A] vs [工具 B]：[场景] 选哪个？
我的答案：[选 X]，因为…
```

例句：
- 「Claude Code vs Cursor：搭自动化系统选哪个？我的答案：Claude Code，因为它能直接操作终端」
